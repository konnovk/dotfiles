# dotfiles-kitty

Персональная конфигурация терминала Kitty.

## Что настроено

- шрифт **Cascadia Mono NF Light** размером 16;
- запуск в полноэкранном режиме;
- скрытие системных декораций окна;
- цветовая тема **Adwaita dark**.

## Файлы

- `kitty.conf` — основные настройки Kitty;
- `current-theme.conf` — цветовая тема Adwaita dark.
